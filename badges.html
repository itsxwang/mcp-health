Badges

Every tested server gets an embeddable SVG badge — the live result of its smoke test, regenerated on each daily run. Put it in your README to show your server boots and answers.

How to embed

Copy the markdown below into your README (replace the URL with your server's badge):

[![MCP Health: PASS](<https://itsxwang.github.io/mcp-health/badges/YOUR-SLUG.svg>)](<https://itsxwang.github.io/mcp-health/server/YOUR-SLUG.html>)

Or plain HTML:

<a href="https://itsxwang.github.io/mcp-health/server/YOUR-SLUG.html"><img src="https://itsxwang.github.io/mcp-health/badges/YOUR-SLUG.svg" alt="MCP Health" width="208" height="20"></a>

Badges are static SVG files regenerated on each daily run — no JS, no tracking, no requests to third parties. Every badge links to the server's full test report.
